# Scientific analysis lock

This repository is intended to preserve the analysis associated with the manuscript.

- Phase 6 is partial, not universal, cross-generator replication.
- Phase 7 uses 216 plant outcomes nested in 18 environmental domains.
- Hourly sensor rows are not independent plant observations.
- Phase 7 H7.1 is not directly identifiable with the available real-data design.
- H7.2 is suggestive and sensitivity-qualified, not confirmed.
- H7.3 is not supported.
- The final severity sensitivity analysis excludes TDS from the compact nonredundant severity representation.
- Negative, non-replicating, and sensitivity-qualified findings must not be changed merely to obtain stronger statistical significance.
